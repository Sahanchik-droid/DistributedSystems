# Echo Client-Server Application

A simple Echo Client-Server application implemented in Python.

## Requirements

- Python 3.6 or higher

## How to Use

### Starting the Server

Run the server:

```bash
python echo_server.py
```

The server will start on port 8888 by default and listen for incoming connections.

### Starting the Client

Run the client in a separate terminal:

```bash
python echo_client.py
```

The client will connect to localhost:8888 by default and prompt you to enter messages.

Enter your message and press Enter. The server will echo back your message.
Type 'quit' to exit the client.
